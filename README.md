# zynqboard_petalinux

PetaLinux 2020.2 project for the HZHY HZ7020 (Zynq-7000) board, with LCD support via Xilinx DRM/KMS.

> **Prerequisite:** Before building, copy the vendor-modified Linux 5.4 kernel source tree into `hz7020_fresh/components/ext_sources/zynq-linux-xlnx/`; the `components/ext_sources/` directory is intentionally excluded by `.gitignore` and is therefore not included in this repository.
